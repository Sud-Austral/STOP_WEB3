# 📘 CONTEXTO MAESTRO: STOP_WEB3 (Sistema Integrado de Análisis Delictual)

## 📋 METADATA
- **Fecha**: 2026-02-18
- **Stack**: Vanilla JS (ES2020+), HTML5, CSS3, Web standard APIs.
- **Browser Support**: Modern only (Chromium 80+, Firefox 113+, Safari 16+) due to native `DecompressionStream` and `async/await` patterns.
- **Criticidad**: CRÍTICA (Dashboard de seguridad pública para toma de decisiones institucionales).

## 🎯 OBJETIVOS DE NEGOCIO
Proporcionar una plataforma de inteligencia territorial para la visualización y análisis de estadísticas criminales en Chile. El sistema permite a las autoridades evaluar el desempeño de gestión (Clúster), la trayectoria histórica (STOP) y el impacto regional (CEAD) mediante tableros dinámicos y reportes exportables a PDF de alta fidelidad.

## 🏗️ ARQUITECTURA TÉCNICA
- **Patrón**: Module Pattern con Global State centralizado. El núcleo reside en `DataManager` (js/data_manager.js) que actúa como *Single Source of Truth*.
- **Flujo de Datos**: 
  1. Carga de taxonomía (`union.json`) y configuración (`cluster.json`).
  2. Fetch de datos gzippeados por Comuna (`data/stop/`, `data/cead_split/`).
  3. Descompresión on-the-fly (`DecompressionStream`).
  4. Población de estado global (`window.STATE_DATA`).
  5. Renderizado reactivo a eventos de carga en vistas (`vistaX.html`).
- **Web Standards Compliance**: 100% Vanilla JS. Sin frameworks (React/Vue/Angular). Uso intensivo de CSS Custom Properties y Grid/Flexbox.
- **Restricciones de Entorno**: 
  - Proceso de datos pesado en cliente (latencia de red compensada por compresión GZ).
  - Generación de PDF dependiente de `html2canvas` y `jsPDF`.

## ⚠️ RESTRICCIONES Y ÁREAS SENSIBLES
- **js/data_manager.js**: Núcleo de la orquestación. Cualquier cambio aquí afecta a todas las vistas.
- **config/columns.js**: Mapeo crítico entre el backend (Python) y el frontend. Una discrepancia de nombres rompe los tableros.
- **Matriz de Riesgo (Vista 13)**: Lógica de delta-colorización sensible a cambios en el orden cronológico de los datos.
- **Deuda técnica**: Dependencia de variables globales (`window.STATE_DATA`) para comunicación entre scripts, requiriendo estricto orden de carga en HTML.
