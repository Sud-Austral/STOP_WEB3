# 📘 CONTEXTO MAESTRO: STOP WEB V2 (Web 3.0 Refactor)

## 📋 METADATA
- **Fecha**: 2026-02-13T20:45:00-03:00
- **Stack**: Vanilla JavaScript (ES2020+), HTML5, CSS3 (Variables & Flexbox/Grid).
- **Lenguajes Backend (Data Processing)**: Python (Pandas, SARIMA, JSON generation).
- **Browser Support**: Modern Browsers (Chrome, Edge, Firefox, Safari). No Legacy Support (IE11).
- **Criticidad**: ALTA (Herramienta de análisis delictual y toma de decisiones).

## 🎯 OBJETIVOS DE NEGOCIO
Proporcionar una plataforma web rápida, interactiva y visualmente rica para el análisis de estadísticas delictuales (STOP y CEAD). El sistema debe permitir la visualización de tendencias, rankings y proyecciones predictivas (IA/SARIMA) para apoyar la gestión de seguridad pública a nivel comunal y nacional. Prioriza la velocidad de carga y la claridad en la visualización de datos complejos.

## 🏗️ ARQUITECTURA TÉCNICA
- **Patrón Principal**: **Singleton State Manager**. `DataManager` (en `js/data_manager.js`) actúa como la única fuente de verdad para el estado de la aplicación (`STATE_DATA`).
- **Estrategia de Módulos**: 
  - **Script Loading**: Scripts ES6 cargados directamente en el HTML (sin bundler en runtime, aunque estructurado para ello).
  - **View Loading**: `index_vistas2.html` actúa como shell (SPA-like) que carga dinámicamente fragmentos HTML (`vistas2/*.html`) e inyecta lógica específica.
- **Flujo de Datos**:
  1. **Python (Offline/Backend)**: Procesa CSVs, entrena modelos SARIMA, genera JSONs estáticos (`data/*.json`, `.config/*.json`).
  2. **DataManager (Frontend)**: Carga JSONs `fetch()`, normaliza datos, enriquece taxonomía (Union), y expone estado global.
  3. **Vistas (UI)**: Consumen `STATE_DATA` y renderizan gráficos (Chart.js) y tablas.
- **Web Standards**: Uso intensivo de `fetch`, `async/await`, `Optional Chaining (?.)`, `Promises`, `Canvas API` (Chart.js).
- **Restricciones de Entorno**: 
  - CSR (Client-Side Rendering) total.
  - Dependencia de archivos estáticos locales/remotos.
  - Integración con API de IA externa (bigmodel.cn).

## ⚠️ RESTRICCIONES Y ÁREAS SENSIBLES
- **Archivos Críticos ("No Tocar" sin validación exhaustiva)**:
  - `js/data_manager.js`: Núcleo de la aplicación. Cualquier error aquí rompe todas las vistas.
  - `notebook/proceso_cead.py`: Lógica compleja de predicción (SARIMA) y saneamiento de datos. Cambios en fechas o lógica de fallback afectan la integridad de los datos.
  - `.config/union.json`: Define la taxonomía unificada.
- **Deuda Técnica Identificada**:
  - Uso de variables globales (`window.STATE_DATA`, `window.COLS`) para comunicación entre vistas.
  - Mezcla de lógica de presentación y datos en algunos scripts de vista.
  - Dependencia de nombres de archivo específicos (`vistaX.html`) para la navegación.
