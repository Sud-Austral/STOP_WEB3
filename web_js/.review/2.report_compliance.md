# 🛡️ REPORTE DE CUMPLIMIENTO (Web Security & Supply Chain)

**❗ Hallazgo**: Carga de librerías externas vía CDN sin integridad de subrecursos (SRI).
**🔓 Vulnerabilidad**: Ataque de cadena de suministro (Supply Chain Attack).
**📍 Ubicación**: `index_vistas2.html` / Líneas 96-100.
**⚠️ Severidad**: Media.
**📜 Estándar/Ley**: OWASP A08:2021-Software and Data Integrity Failures.
**🛠️ Mitigación**: Implementar atributos `integrity` (hash SHA-384) y `crossorigin="anonymous"` en todas las etiquetas `<script>` que apunten a dominios externos.

---

**❗ Hallazgo**: Riesgo de XSS basado en DOM mediante manipulación directa de `.innerHTML`.
**🔓 Vulnerabilidad**: DOM-based Cross-Site Scripting (XSS).
**📍 Ubicación**: `js/utils/ui-helper.js` / Línea 70, y múltiples vistas (frecuentemente en inyecciones de tablas).
**⚠️ Severidad**: Alta (Si los datos del backend no están debidamente sanitizados o son interceptables).
**📜 Estándar/Ley**: OWASP A03:2021-Injection.
**🛠️ Mitigación**: Utilizar `.textContent` para datos planos. Para fragmentos HTML, implementar una función de sanitización (ej. DOMPurify) o construir el DOM mediante `createElement`.

---

**❗ Hallazgo**: Exposición de lógica de negocio y estructura de datos en el cliente.
**🔓 Vulnerabilidad**: Exposición de información sensible/arquitectura.
**📍 Ubicación**: `js/data_manager.js` / `config/cluster.json`.
**⚠️ Severidad**: Baja.
**📜 Estándar/Ley**: OWASP A01:2021-Broken Access Control (Information Disclosure).
**🛠️ Mitigación**: Aunque es un dashboard cliente, se debe asegurar que los endpoints de datos tengan autenticación robusta y que los archivos `json` de configuración no contengan metadatos innecesarios del servidor.
