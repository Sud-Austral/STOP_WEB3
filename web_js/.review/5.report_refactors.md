# 🛠️ Plan de Refactorización: refactor-suggester

## 📋 Contexto
Basado en hallazgos de Seguridad, Calidad y Arquitectura.

## 📝 Prioridades (P0 - Crítica / P1 - Alta / P2 - Media)

### 1️⃣ Proxy Seguro para API IA (P0 - Seguridad)
**🔨 Refactor**: Implementar Proxy Intermedio.
**🎯 Objetivo**: `2.report_compliance.md` (Secret Exposure).
**💻 Estrategia**:
- **Before**: `js/ia2.js` llama a `open.bigmodel.cn` directo con `API_KEY` ofuscada.
- **After**: `js/ia2.js` llama a `/api/proxy/ia` (mismo dominio). El servidor (Python/Node) inyecta la `API_KEY` y reenvía.
**⚠️ Riesgo**: Alto (Requiere backend real). Si no hay backend, usar **Cloud Function** (Vercel/Netlify/Firebase) gratuita.
**⏱️ Esfuerzo**: M (Configurar + Deploy).

### 2️⃣ Manejo de Errores Global (P1 - Robustez)
**🔨 Refactor**: Global Error Boundary + Toast UI.
**🎯 Objetivo**: `1.report_errors.md` (Silent Failures).
**💻 Estrategia**:
- **Before**: `console.error` invisible.
- **After**: `window.onerror` captura excepciones no manejadas y muestra `<div class="toast error">...</div>`.
- **Snippet**:
```javascript
window.addEventListener('unhandledrejection', event => {
    UI.showToast(`Error de Red/Carga: ${event.reason.message}`, 'error');
});
```
**⚠️ Riesgo**: Bajo.
**⏱️ Esfuerzo**: S (1 hora).

### 3️⃣ Centralizar Lógica de UI (P2 - DRY)
**🔨 Refactor**: `UIHelper` module.
**🎯 Objetivo**: `3.report_code_quality.md` (Duplicate Logic).
**💻 Estrategia**:
- **Before**: `vistas2/*.html` repiten lógica de `kpi-change`.
- **After**: `UI.renderTrend(element, value)` o `web-component <rd-trend value="..."/>`.
**⚠️ Riesgo**: Medio (Requiere editar 25 archivos).
**⏱️ Esfuerzo**: M (3-4 horas).

### 4️⃣ Caché DOM Inteligente (P2 - Performance)
**🔨 Refactor**: `DocumentFragment` / `DOMCache`.
**🎯 Objetivo**: `3.report_code_quality.md` (Layout Thrashing).
**💻 Estrategia**:
- **Before**: `document.getElementById` en loops.
- **After**: Cachear referencias en `App.elements = { ... }` al inicio.
**⚠️ Riesgo**: Bajo.
**⏱️ Esfuerzo**: S (1-2 horas).

### 5️⃣ Migración a ES Modules (P3 - Arquitectura)
**🔨 Refactor**: `type="module"`.
**🎯 Objetivo**: `4.report_architecture.md` (Script Loading).
**💻 Estrategia**:
- **Before**: `<script src="js/data.js"></script>`...
- **After**: `<script type="module" src="js/main.js"></script>`. `js/main.js` hace `import ...`.
**⚠️ Riesgo**: Alto (Breaking changes en orden de ejecución). Hacer incrementalmente.
**⏱️ Esfuerzo**: L (1-2 días).

## 🚀 Hoja de Ruta Sugerida
1.  **Semana 1**: Implementar Proxy (P0) y Error Boundary (P1).
2.  **Semana 2**: Refactorizar Vistas a usar `UIHelper` (P2) y limpiar código duplicado.
3.  **Semana 3**: Migrar a ES Modules (P3) y optimizar carga.
