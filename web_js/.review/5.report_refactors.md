### 🚀 Próximos Pasos Prioritarios

#### 1️⃣ Proxy Seguro para API IA (P0 - Seguridad)
**🔨 Refactor**: Implementar Proxy Intermedio.
**🎯 Objetivo**: `2.report_compliance.md` (Secret Exposure).
**💻 Estrategia**:
- **Before**: `js/ia2.js` llama a `open.bigmodel.cn` directo con `API_KEY`.
- **After**: Crear un endpoint (Node/Python) que inyecte la key. `js/ia2.js` llama a ese endpoint.
**⚠️ Riesgo**: Alto (Requiere backend).
**⏱️ Esfuerzo**: M.

#### 2️⃣ Refactorización Masiva de Vistas (P2 - Calidad)
**🔨 Refactor**: Aplicar `UIHelper` a Vistas 2-25.
**🎯 Objetivo**: `3.report_code_quality.md` (DRY).
**💻 Estrategia**:
- Reemplazar bloques manuales de DOM (`innerHTML`, `style.color`) por `RID.UI.renderKpi(...)` en todas las vistas restantes.
**⚠️ Riesgo**: Medio (Testear cada vista).
**⏱️ Esfuerzo**: L (Trabajo mecánico).

#### 3️⃣ Fix Race Condition IA (P1 - Robustez)
**🔨 Refactor**: Cancelación de peticiones / Validación de DOM.
**🎯 Objetivo**: `1.report_errors.md` (Race Condition).
**💻 Estrategia**:
- En `updateAllViews`, verificar si la vista actual sigue activa o usar un `AbortController` para cancelar fetches obsoletos.
**⚠️ Riesgo**: Bajo.
**⏱️ Esfuerzo**: S.
