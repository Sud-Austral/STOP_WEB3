### REF-001: `Promise.allSettled` en DataManager
**🔨 Refactor**: Reemplazar `Promise.all` con `Promise.allSettled` para tolerancia a fallos parciales.

**🎯 Objetivo**: ERR-001 (error-watcher) — Criticidad: **Crítica**

**💻 Before**:
```javascript
// js/data_manager.js:81
await Promise.all([
    this.loadStopData(this.state.comunaId),
    this.loadCeadData(this.state.comunaId),
    this.loadClusterConfig(),
    this.loadComunasData()
]);
this.state.isLoaded = true;
```

**💻 After**:
```javascript
const results = await Promise.allSettled([
    this.loadStopData(this.state.comunaId),
    this.loadCeadData(this.state.comunaId),
    this.loadClusterConfig(),
    this.loadComunasData()
]);
const labels = ['STOP', 'CEAD', 'Cluster', 'Comunas'];
results.forEach((r, i) => {
    if (r.status === 'rejected') {
        console.warn(`⚠️ ${labels[i]} falló:`, r.reason?.message);
    }
});
// Cargado si al menos una fuente primaria tuvo éxito
this.state.isLoaded = results[0].status === 'fulfilled' || results[1].status === 'fulfilled';
```

**⚠️ Riesgo**: Bajo — Backward compatible, no cambia la interfaz.  
**⏱️ Esfuerzo**: **S** (15 min)

### REF-002: Centralizar `waitForData()` con Timeout
**🔨 Refactor**: Crear una función reutilizable en `js/utils/waiter.js` y reemplazar las ~27 copias en vistas.

**🎯 Objetivo**: ERR-002 (error-watcher) + CQ-001 (code-reviewer)

**💻 Código Centralizado**:
```javascript
// js/utils/waiter.js
window.waitForSTOP = (timeoutMs = 15000) => new Promise((resolve, reject) => {
    const t0 = Date.now();
    const poll = () => {
        if (window.STATE_DATA?.isLoaded) return resolve(window.STATE_DATA);
        if (Date.now() - t0 > timeoutMs) return reject(new Error('Timeout: datos STOP'));
        setTimeout(poll, 200);
    };
    poll();
});

window.waitForCEAD = (timeoutMs = 15000) => new Promise((resolve, reject) => {
    const t0 = Date.now();
    const poll = () => {
        if (window.STATE_DATA_CEAD?.isLoaded) return resolve(window.STATE_DATA_CEAD);
        if (Date.now() - t0 > timeoutMs) return reject(new Error('Timeout: datos CEAD'));
        setTimeout(poll, 200);
    };
    poll();
});
```

**💻 En cada vista** (Before → After):
```javascript
// BEFORE (27 copias, cada una diferente)
const waitForData = () => new Promise(resolve => {
    const check = () => {
        if (window.STATE_DATA && window.STATE_DATA.isLoaded) resolve();
        else setTimeout(check, 100);
    };
    check();
});
await waitForData();

// AFTER (1 línea)
const S = await waitForSTOP();
```

**⚠️ Riesgo**: Bajo  
**⏱️ Esfuerzo**: **S** (~1h para las 27 vistas, es mechanical replacement)

### REF-004: Timeout en `IAModule.getInterpretation()`
**🔨 Refactor**: Añadir límite de 30s al busy-wait de interpretaciones IA.

**🎯 Objetivo**: ERR-003 (error-watcher)

**💻 Before**:
```javascript

    await new Promise(resolve => setTimeout(resolve, 100));
```

```javascript

    await new Promise(resolve => setTimeout(resolve, 200));

```

**⚠️ Riesgo**: Bajo
